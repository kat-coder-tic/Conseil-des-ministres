# 🏛️ Gouvernement : La Crise de l'Emploi - Version 3.0 Enrichie

## Serious Game pédagogique pour Terminale STMG - Économie

Un serious game interactif développé pour les **Thèmes 6.3, 6.4 et 7 du programme d'économie STMG** : 
- **Thème 6.3** : *Quelles sont les principales défaillances du marché et comment l'État peut-il améliorer son fonctionnement ?*
- **Thème 6.4** : *Comment les politiques sociales visent-elles à améliorer la cohésion sociale ?*
- **Thème 7** : *Quelle est l'influence de l'État sur l'évolution de l'emploi et du chômage ?*

### 🆕 Nouveautés Version 3.0

✨ **25 politiques** (au lieu de 12) - Thèmes 6.3 & 6.4 intégrés
✨ **23 événements** (au lieu de 10) - Positifs ET négatifs
✨ **13 indicateurs** (au lieu de 7) - Dashboard enrichi
✨ **60% de chance** d'événement par trimestre (au lieu de 30%)
✨ **Catégorisation visuelle** des politiques par ministère

### 🎯 Objectifs pédagogiques

Les élèves apprennent à :
- **Thème 7** : Définir et calculer les indicateurs du marché du travail, distinguer les formes de chômage, identifier et catégoriser les politiques de l'emploi
- **Thème 6.3** : Comprendre les politiques économiques (budgétaire, fiscale, concurrence), analyser les arbitrages déficit/croissance, maîtriser les contraintes européennes
- **Thème 6.4** : Identifier les politiques sociales (santé, retraites, minima sociaux), mesurer l'impact sur la pauvreté et les inégalités, comprendre le financement de la protection sociale
- **Transversal** : Analyser les arbitrages complexes, gérer des contraintes multiples, adapter sa stratégie aux événements

### 🎮 Gameplay

**Durée** : 1h40-2h (adaptable selon le temps disponible)

**Mode Campagne avec 4 scénarios** :
1. **🔴 Crise Économique** (Très difficile) - Chômage 14%, récession
2. **🟡 Situation Standard** (Moyen) - Chômage 12%, économie stable  
3. **🟢 Boom Économique** (Facile) - Chômage 9%, forte croissance
4. **🏭 Désindustrialisation** (Très difficile) - Chômage 15%, fermetures d'usines

**Déroulement** : L'élève choisit un scénario et dispose de **8 trimestres (2 ans)** pour atteindre l'objectif spécifique.

**Mécaniques** :
1. **Sélection du scénario** : Choix de la difficulté et du contexte économique
2. **Phase de diagnostic** : Analyse de la situation initiale
3. **8 phases de décision** : Choix de 3 mesures maximum par trimestre parmi **25 politiques**
4. **Rapport de mi-parcours** : Bilan après 1 an (4 trimestres) avec recommandations
5. **Événements aléatoires** : **60% de chance** par trimestre (**23 événements** différents)
6. **Bilan final** : Évaluation des performances et comparaison avec l'objectif

### 📊 Fonctionnalités

✅ **Mode Campagne avec 4 scénarios** :
- Crise économique (très difficile) - 65% événements
- Situation standard (moyen) - 60% événements
- Boom économique (facile) - 55% événements
- Désindustrialisation (très difficile) - 70% événements
- Chaque scénario a ses propres objectifs, difficulté et événements

✅ **8 trimestres (2 ans) de jeu** :
- Vision à moyen/long terme
- Stratégies plus élaborées
- Rapport de mi-parcours après 1 an

✅ **25 politiques multi-ministères** (Thèmes 6.3, 6.4, 7) :
- **💼 Emploi** : Formation, aides embauche, création entreprise, indemnisation
- **💰 Économie** : Réforme fiscale, politique concurrence, austérité, soutien crédit, politique industrielle, lutte inflation
- **🏥 Social** : Couverture santé, RSA, logement social, aide alimentaire, retraites
- **🎓 Éducation** : Investissement éducation, apprentissage

✅ **13 indicateurs économiques et sociaux** :
- **Emploi** : Chômage, emploi, activité, budget
- **Économie** : Croissance, déficit public, dette publique, inflation
- **Social** : Pauvreté, inégalités, popularité
- **Acteurs** : Satisfaction entreprises/salariés

✅ **23 événements aléatoires** (positifs ET négatifs) :
- **Négatifs** : Crise mondiale, crise bancaire, délocalisation, grève, manifestations, crise logement, pauvreté, scandale santé, guerre commerciale, hausse énergie, crise réfugiés, pandémie
- **Positifs** : Innovation, implantation multinationale, relocalisation, transition écologique, accord commercial

✅ **Rapport de mi-parcours** : Analyse après 4 trimestres avec recommandations stratégiques

✅ **Sauvegarde automatique** : Le jeu peut être mis en pause et repris ultérieurement

✅ **Système de budget renouvelable** : Les recettes fiscales se renouvellent chaque trimestre
- Recettes de base : ~25% par trimestre
- Bonus selon la croissance économique
- Bonus selon le taux d'emploi
- Plafond à 150% pour éviter les abus

✅ **Système de scoring** : Évaluation sur 4 dimensions avec feedback pédagogique

### 🎓 Points pédagogiques clés

Le jeu illustre concrètement :
- Les **arbitrages économiques** : efficacité vs coût, court terme vs long terme
- Les **effets de bord** : une mesure peut avoir des impacts positifs ET négatifs
- L'**incertitude** : les événements externes peuvent bouleverser les plans
- La **complexité** des politiques publiques : pas de solution miracle
- L'importance de la **cohérence** : certaines combinaisons de mesures sont plus efficaces
